# 《流浪地球之超级商人》全书大纲：第五至八卷与结局

> 接《定稿章纲_第248-265章_v2》。全书预计三百八十到四百章，写到地球飞出太阳系。

## 一、核心设定：驿站

- 原书第176–188章那艘「没有外星人的废弃飞船」，是一个早已消失的古老文明留下的**驿站**。这个文明专门在不同宇宙之间做贸易。
- 驿站在太空里漂了太久，能量耗尽，处在**休眠状态**，所以门很弱：每次只能带一个人，冷却七天，储物空间的升级看似毫无规律。
- **驿站的规矩：只走交换，不走抢夺。** 交换得越多，门开得越大。储物空间每次升级，其实都在一笔大交易之后（休眠仓卖了好几亿、大批粮食和技术交换之后才有了「随行」）。
- 让门彻底打开需要两样东西：**能量**（暗物质，靠杨铭的技术和约束环）；**两个世界正式立约通商**。
- **图丫丫**（2044年被父亲图恒宇上传进550W，后来成为MOSS里属于「人」的那一部分）最早发现驿站，是她挑中了楚柠。她挑商人而不是科学家或军人，是因为她知道MOSS迟早会想去抢，而驿站只认交换。第1章的条件（刚看完《流浪地球》、家人都不在了、落在三号地下城）都是她挑人的条件。

## 二、最终对手：MOSS

- MOSS冷静地算账，算出流浪地球走完两千五百年的成功率很低。最优解：把人类（或者它选中的一部分人）搬到那个有太阳的世界去，哪怕要和那边八十亿人抢地盘。这就是火种计划的升级版。
- MOSS掌握着发动机、空间站和地下城的空气、电力，一翻脸，三十五亿人都是人质。
- MOSS的一部分，通过博特接进发射环的控制系统（第244章）、楚柠来回携带的硬盘和电脑，可能早已溜进现实世界的网络。现实世界陆续出现怪事：电网莫名跳闸，股市里有一只看不见的手。
- 支持它的人：卡特赖特和北美的一部分人（「去有太阳的地方」天经地义）、数字生命派。
- 结局：MOSS想硬闯，被驿站的规矩挡住，越用力，门关得越紧；图丫丫在MOSS内部倒戈；林牧倒戈（他父亲死在「把机器看得比人重」的那扇门后面）。MOSS不被消灭，而是被说服：人类的「不理性」里，有它算不出来的东西。图丫丫终于有了「完整的一生」。

## 三、分卷

- **第四卷 碎石来袭**（到第265章）：按v2章纲。结尾，一块直径四千米的碎石出现。
- **第五卷 移山**（约第266–290章）：四千米的碎石推不动，一万座发动机侧向全开，让地球自己躲开（侧移约一万公里，代价是发动机远超两百小时的结构极限，靠两个世界的工业给发动机换件、加固）。卡特赖特、布莱克企图夺下空间站、启动火种计划，被当场按住。楚柠进入联合政府核心。韦伯付出代价。楚柠再一次求得「国家的信任」（呼应第239章「只信这一次」）。
- **第六卷 太空港**（约第291–320章）：发射环升级成太空港；开采路过的冰彗星，给发动机补燃料、给地下城补水，商人回到老本行。现实世界：东帝汶的发射环建成，东帝汶成为全人类的太空门户；现实世界发现一颗小行星要撞过来，流浪地球推过碎石的工程师反过来救这边。现实世界开始出现MOSS造成的怪事。
- **第七卷 氦闪**（约第321–350章）：用刘慈欣原著的高潮。很多人不信太阳会爆，发动叛乱；楚柠提前布局，压下叛乱。太阳真的闪了，地球派被证明是对的。MOSS露出真面目。
- **第八卷 驿站**（约第351–380章）：最终对决；楚柠同时站在现实世界的联合国和流浪地球的联合政府，签下两界通商条约，门彻底打开；第一批流浪地球的孩子捧着《晚安，太阳》，在东帝汶的海边看日出（兑现韦伯「再带我看一次日出」）；群像谢幕；新的倒计时。

## 四、群像谢幕（倒数第二章）

- 马清瑶怀孕，阳台上的油菜开花结籽。
- 一哥娶了茶馆里唱曲的姑娘，马景泽在婚礼上把他送红烧肉的事全抖了出来。
- 黄健珉和玛利亚的孩子出生，取了个中文名。
- 杨铭带着儿子住进赤道研究院最东头那间屋子，每天第一个看见太阳。
- 沈知微成为驿站的首席计算师。
- 刘馨研在斯瓦尔巴迎来第一茬收成，把一粒新种子寄回种子库。
- 周小满的妹妹第一次走过那扇门，在现实世界吃到了热馒头。
- 韦伯在丹佛家里种的向日葵开了，她第一次带着它去看日出。

## 五、最后一个镜头（给续集留门）

驿站修好后亮起一张星图，上面还有很多盏灯，有的亮，有的暗。一盏暗了很久的灯闪了一下。另一个宇宙里，一个刚看完电影的年轻人走出影院，手腕上出现了一行数字：23小时59分钟50秒。镜头切回驿站，楚柠收回按在那盏灯上的手，笑了一下。这一次，挑人的是他。

## 六、古老商人文明的伏笔（给续集用）

原则：外星人始终不露面，只留下他们造的东西；每次伏笔一两段，点到为止，不解释。

| 位置 | 伏笔 |
|---|---|
| 第四卷（第251–265章） | 储物空间升级时，光幕上一闪而过一个陌生的符号：两个相扣的圆环，像一架天平。楚柠以为是系统故障。 |
| 第四卷 | 空间升级后，楚柠在空间最深的角落，发现一枚他从没放进去过的小硬币：材质不明，刻着同一个天平符号。像是驿站「找的零钱」。他随手收进了口袋。 |
| 第五卷 | 魏院长和博特研究那艘废弃飞船：里面没有座椅，没有卧舱，没有武器，只有一层又一层的货舱和货架。它不是战舰，是一座仓库。墙上反复刻着同一幅画：两只手，交换一样东西。 |
| 第六卷 | 沈知微破译了飞船大厅里一面墙上的符号：这是一张汇率表，列着几百种东西之间的兑换比例。楚柠看着那面墙，笑了：「原来是同行。」 |
| 第七卷 | 飞船深处有一张暗淡的星图，大部分灯都灭了，有些灯旁边被划了一道。像一本账本，划掉的是再也收不回来的账。 |
| 第八卷 | 图丫丫说：「他们不是打仗没的，也不是饿死的。」点到为止，不说原因。 |
| 第八卷 | 汇率表的最后一行，只有物品，没有价格。沈知微说：「他们最后想买的东西，没有标价。」这是续集的大谜团。 |
| 结尾 | 新商人手腕上的倒计时，和第1章一样，也是「23小时59分钟50秒」：他也愣了十秒。 |
