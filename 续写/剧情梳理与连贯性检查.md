# 《流浪地球之超级商人》剧情梳理与连贯性检查

本报告分四部分：原书第1–212章梳理、续写第213–236章（已写）梳理、续写第237–257章（待写）梳理、连贯性和爽文风格检查。

## 一、原书剧情梳理（第1–212章，作者"专门无名之辈"）

### 1. 起家（第1–31章）
- 东帝汶华人楚柠看完电影《流浪地球》，穿越到首都三号地下城，手腕上出现只有他看得见的光幕，附带一个衣柜大小的储物空间。
- 用肉罐头敲开黑市老大一哥的门，收下断腿的陈志远、刘启、巨汉铁牛、退伍兵赵军，组建搜荒队。
- 和天津野外避难所的刘馨研签下"粮食换工业设备"的长期交易。
- 现实世界里：卖黄金、钻石起家，请邻居张向北开公司；把精密机床卖给国企得30亿人民币；在羊城成立龙行晶片。

### 2. 崛起（第32–93章）
- 流浪地球那边造出的光刻机运到现实世界，"3nm龙芯"轰动全球。
- 楚柠当上三号地下城粮食办主任，与马尚一家结缘，和马清瑶互有好感。
- 红钻"太空之心"拍出十一亿美元；他原价买下圆明园羊首捐给国家；出资五亿请袁老研究高寒弱光种子。
- 在东帝汶花钱买下国防军将军一职，开始整军。
- 终端多次升级：空间扩大到160立方米，新增"低温生存"。
- 石家庄地下城的蒙老将军合作建电池厂；用一包椰子糖从旧货摊换到霍奇猜想的证明光碟；收下收藏家丁诚当鉴定师；在二号城结识嗜酒的周局长，换到休眠仓。
- 比亚迪电池、白菜生意、东帝汶扩军，一步步展开。

### 3. 扩张（第94–155章）
- 招揽制药专家罗华，糖尿病特效药上市；休眠仓在现实世界卖出两亿美元一台；空间升级到足球场大小。
- 澳洲、印尼先后对东帝汶退让。3nm手机、新电池、特效药接连在中国引爆市场。
- 修建百万吨级的长城粮仓；推出"流浪者"香烟；一哥开连锁超市。
- 杭城：魏院长（参与研发过MOSS）合作；杭城大学建食堂、资助博特和肖芒做量子计算机。
- 刘馨研和野外大势力七爷做生意，用菠萝换回钻石。
- 现实世界：家庭机器人热卖；龙行赞助国家女足。
- 楚柠升任部长；在长安找到张衡地动仪原品，以及达·芬奇的《救世主》。

### 4. 鼎盛（第156–212章）
- 长安收藏家蔡宝东拿二十万件文物换红酒；叶飞团队研发出塑料分解酶，获诺贝尔奖提名。
- 马尚当选联合政府核心委员；酒泉王星送来淘汰的火箭技术；楚柠访华，签下六七百亿协议，成立航天公司，宣布载人登月。
- 联合政府发现一艘外星飞船，后来发现是废弃的，没有外星人（第176–188章）。
- 刘启带朵朵出走寻亲（楚柠自己说"剧情提前了"）；地动仪提前预警印尼大地震，东帝汶几乎毫发无伤。
- 3D打印器官、采矿机器人、科学家杨铭发现并捕捉暗物质、马景泽从西伯利亚带回两个俄罗斯姑娘、国家入股龙行、空间站驻守员招聘。
- 华南多座地下城的代表团来求粮；京广高铁重启，改成粮食专列；楚柠承诺"一年后向其他地区供粮"（第203–204章）。
- 在冰封的太湖里找到美军核潜艇上的核弹；东帝汶对澳洲、印尼宣战，在澳洲沙漠投下核弹，收回西帝汶（第205章被封，只能从后文推知）。
- 大飞机短舱技术卖了八百五十亿；中国登月建基地；龙行在月球开采氦三；楚柠把可控核聚变技术交给中国。
- 第212章：楚柠交完技术，准备回公司。断更。

### 5. 原书的风格特征
- **核心爽点**：两界价值颠倒，一边的垃圾是另一边的宝贝；楚柠在心里算账，常用"几罐肉罐头换了三十个亿"这类对比。
- **打脸套路**：外界质疑、楚柠拿出成果、配角震惊、网友刷屏。
- **文风**：短段落；大量内心吐槽（"得！""好家伙！"）；频繁插入科普段落。
- **结构**：两个世界轮流写，常用小人物视角（王嫂、拉莫斯、樱子）。
- **毛病**：有歧视性称呼；一些设定前后矛盾（如"木星之后是小行星带"）；很多支线开了头没收尾。

## 二、续写剧情梳理（第213–236章，已写完）

### 第一卷 木星将至（第213–224章）
- 终端升级出"随行"功能，能带一个人往返，冷却七天。铁牛第一个过去，见到了太阳、大海、月亮。
- 木星危机提前到四个月后。杨铭提出暗物质耦合设想，楚柠把他带到现实世界，借超级计算机和材料做出"约束环"，第一台失超炸毁，第二台成功。
- 联合政府里北美、东亚角力，MOSS评估成功率3.2%，马尚以身家担保争来试点。
- 婚礼；第一座发动机点火成功；全国四十七家工厂赶制两万吨材料。
- MOSS启动火种计划，委员提前送家属逃跑的丑闻曝光。楚柠提前布局杭城，救下上万人。

### 第二卷 冲过木星（第225–236章）
- 马卡洛夫用伏特加打开核心舱，火种计划中止；全球装机；地球以离洛希极限只多四万公里的距离冲过木星。
- 马清瑶来现实世界看花海。京广高铁通车，第一趟粮食专列开到羊城。
- 现实世界：油价暴跌、美国组建深空联盟、假海底基地骗过美国、美国制裁被楚柠三个电话反制。
- 流浪地球：修通往西北和西伯利亚的铁路，楚柠和罗斯夫结拜；"一年之约"的粮食外交；卡特赖特的粮食公有议案被否决。

## 三、续写剧情梳理（第237–257章，待写，按最新设计）

- **主线一：太空电梯。** 重建《流浪地球2》里倒塌的太空电梯。
- **主线二：碎石来袭。** 木星甩出的千米级碎石追击地球，电梯用来往太空运拦截器。
- **主线三：两界经济共同体。** 楚柠搭建一套哪天没有他也能运转的体系：赤道研究院、缆绳材料、斯瓦尔巴种子、粮食自给。
- **《流浪地球2》元素**：550W和MOSS的往事、周喆直客串、数字生命派残余当反派、刘培强和韩朵朵的往事、MOSS深处图丫丫的声音。
- **第237–242章（加强冲突版）**：
  - 韦伯抓到楚柠的实证把柄，只求看一眼太阳，成为卧底；她消失七天，马夫人帮忙打掩护；
  - 中国国安部门追问杨铭身份；
  - 美国中情局拿杨铭的酒杯做同位素检测；
  - 女足决赛与郑佳父亲的心脏手术同时进行；
  - 电梯废墟上和数字生命派对峙，魏院长的旧账被揭开。
- **第243–257章**：
  - 沈知微加入研究院，在北大验证会上折服周院士，获菲尔兹奖；
  - 斯瓦尔巴取种子；马景泽成婚；七爷去世；数字生命派炸电梯工地；
  - 叶飞演示分解酶；第一根缆绳升上同步轨道；杨铭父子重逢；东帝汶海军演习；美国租月球舱室；
  - 结尾：推开第一块碎石，更大的一块正在逼近。

### 2. 设定上的矛盾，以及处理办法

1. **"木星之后是小行星带"（原书第61章）**：天文上不对，小行星带在火星和木星之间。续写改成木星甩出的碎石，已修正。
2. **杨铭在现实世界的身份**：
   - 已写的第217章靠蔡大使秘密安排；
   - 待写的第239章，国安部门追问身份；
   - 待写的第245章，楚柠给他办东帝汶国籍。
   - 三处要统一。建议：第239章国家答应"不追问、打掩护"，同时由东帝汶给他正式国籍和护照，他以东帝汶籍华人科学家的身份领奖；第245章顺势建赤道研究院。这样前后一致。
3. **章节顺序**：第232、233章对调尚未执行，确认后再调。
4. **和电影的差异**：电影里刘培强、韩子昂牺牲，木星危机靠"点燃木星"解决；续写里两人都活着，靠约束环冲过木星。原书第180章借楚柠之口说过"剧情提前了"，可以用蝴蝶效应解释，读者能接受。
5. **人口数字**：流浪地球全球约35亿人。第234章已经按各区人口调整，后面要沿用同一套数字。
6. **周喆直的年龄**：《流浪地球2》里他已年过半百，到2072年约九十岁，坐轮椅客串，说得通。
7. **随行冷却七天**：第238章韦伯消失七天的危机，正是从这条规则来的，用得好。终端如果后面再升级，规则要交代清楚。

### 3. 爽文风格的一致性

**做得好的地方**
- 两界价值颠倒的爽点保留了，而且规格升级：工艺换产能、技术换国家级合作。
- 先压后扬、当众打脸的结构稳定。
- 小人物视角的感染力强：老孙开火车、拉莫斯、刘大强、汤姆农场主。
- 群像名场面有分量：婚礼、全球装机、冲过木星。
- 硬科幻细节让爽点更可信：约束环失超、结构应力、冻土路基、洛希极限。

**需要注意的问题**

1. **"专家鞠躬"用得太多。** 郑教授（第217章）、王主任（第222章）、哈佛教授（第240章）、周院士（第247章），都是"质疑→被折服→鞠躬"，读多了会腻。建议后面几次换花样：
   - 周院士改成写公开信，不当面鞠躬；
   - 王主任改成主动请缨跑工厂；
   - 让有的人嘴上不服、行动上服。
2. **"网友刷屏"段落太密。** 几乎每章现实世界都有一段。建议隔一章用一次，或者换成别的形式：新闻标题、外国媒体头版、外交部发言人、某个具体网友的故事。
3. **离原书的商人底色有点远。** 原书的核心是倒卖算账的快感，续写这几十章，大事件和情感戏的比重越来越高。建议：
   - 每两三章恢复一次楚柠在心里算账的"两界汇率"桥段；
   - 原书里一哥、马景泽那种插科打诨的轻松戏多一点。
4. **情感戏有点密。** 落泪的场面多：铁牛、杨铭、马清瑶、老孙、羊城小伙、奥卡福、郑佳……效果虽好，太密会冲淡。建议每章最多一个泪点，其余用笑点调剂。
5. **主角得付出代价。** 前面楚柠几乎没受过挫。待写的第237–242章，已经设计了被抓把柄、信任有额度、团队出现裂缝，后面要保持，偶尔让他真正输一次，比如数字生命派炸工地造成伤亡，他要为此自责。
6. **反派要更立体。** 卡特赖特是老练的政客，好；数字生命派有理念，好。北美布莱克等人别写成脸谱化的坏人。

### 4. 总体判断

- **连贯性**：原书主线（两界倒卖、粮食供应、科技输出、东帝汶崛起、联合政府政治）在续写里都有延续，大部分伏笔已回收或已安排回收。设定矛盾有三处需要统一：杨铭的身份、章节顺序、小行星带的天文修正。都不难改。
- **爽文风格**：整体在爽文的路子上，而且比原书更有层次。主要风险是套路重复（专家鞠躬、网友刷屏）、情感戏过密，以及离原书"倒卖算账"的轻快底色有点远。按上面的建议调，在写第237章之前就可以落实。
